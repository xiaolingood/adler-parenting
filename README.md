# adler-parenting

一个面向普通家长的中文亲子教育 skill，基于阿德勒心理学、德雷克斯《孩子：挑战》和简·尼尔森《正面管教》，并用现代发展心理学研究做校验。

它不是“修理孩子”的话术库，而是帮家长看清亲子互动的循环，找到自己可以改变的那一步。

**1.1.0 新增**：正式接入《正面管教》的工具层，包括和善而坚定、积极暂停、家庭会议、日常惯例表、关注解决问题、特殊时光、鼓励、启发式提问、错误是学习的机会，以及按年龄使用的工具矩阵。

**1.2.0 变更**：补齐“工具问题”入口和输出骨架；统一为“每条消息只问一个问题”；工具选择指向统一工具库；新增回答前自检；修正一处出门安全措辞；description 前置高频场景词；合并重复的工具段；新增青春期参考文件并把适用范围扩展到 2–18 岁；评测改为 must / must_not 可判定规则并补 5 个安全用例。

## 适用范围

主要面向约 **2–18 岁**；其中 2–12 岁是本 skill 的核心适用范围，13 岁以上改用青春期框架。

- **2–10 岁**：四种行为目的、教养原则和案例库的适用度较高。
- **11–12 岁**：进入青春期早期，四种目的只能作为参考，需要增加协商、隐私和自主。
- **13 岁以上**：不建议直接套用四种行为目的；按 `references/adolescence.md` 的青春期框架，强调协商、隐私、身份认同和风险。
- 本 skill 是教育性内容，不替代医疗或心理诊断。

## 能做什么

**具体问题模式**

家长描述一个正在发生的困扰，例如：

- 磨蹭、不写作业、挑食、发脾气
- 顶嘴、打人、兄弟姐妹冲突
- 屏幕时间、睡前拖延、丢三落四

skill 会先问清楚关键信息，然后：

1. 画出亲子互动的循环；
2. 判断行为背后的可能目的，并给出其他解释和确定性；
3. 给出今晚就能用的话术和动作；
4. 解释为什么有效；
5. 如果问题反复，补长期方案。

**育儿愿景模式**

家长提出“我希望孩子独立/自律/自信/有责任感”，skill 会：

1. 把愿景翻译成可观察的行为；
2. 对照年龄判断期待是否合理；
3. 如果过高，直接说明并给出更现实的目标；
4. 给出家长可以做的环境、规则、话术和放手边界；
5. 解释为什么合理、为什么有效。

**正面管教工具模式**

家长问“积极暂停怎么用”“家庭会议怎么开”“逻辑后果能不能用”“和善而坚定怎么做”时，skill 会：

1. 先确认孩子年龄和使用场景；
2. 从《正面管教》的工具箱里选一个主要工具；
3. 给出步骤、话术、适用年龄和禁忌；
4. 解释为什么有效，以及常见的误用。

## 设计原则

- **看互动，不看标签**：分析行为循环，不评价孩子人格。
- **目标是假设，不是诊断**：四种行为目的只是理解互动的假设，必须给出依据、其他解释和确定性。
- **先澄清，再分析**：信息不够时，每条消息只问一个问题，总共最多三个。
- **原则用名称，不用编号**：不同版本编号不同，编号对家长也没有意义。
- **证据标注**：区分“阿德勒/正面管教取向的常见解释”“现代研究支持”“有争议/需调整”“书外补充”。
- **一次只用一个主要工具**：其他放进“如果继续”或“长期”，避免家长一次改太多。
- **安全优先**：不建议体罚、羞辱、威胁抛弃、剥夺基本需求；自然后果不能以真实伤害为代价；积极暂停不能变成惩罚性隔离。
- **不替代专业帮助**：不诊断多动症、自闭症、抑郁、焦虑等；涉及发育、心理或安全问题时，建议专业评估。

## 安装

### Claude Code

把包含 `SKILL.md` 的内层 `adler-parenting` 文件夹放到：

```text
~/.claude/skills/adler-parenting/
```

Windows 默认路径：

```text
C:\Users\<你的用户名>\.claude\skills\adler-parenting\
```

注意：如果下载包外面还有一层版本目录（例如 `adler-parenting-1.2.0`），要拷贝里面那层 `adler-parenting`，不要连外层一起拷。Claude Code 只扫描 `skills/<名字>/SKILL.md`，多一层目录会找不到技能。

重启 Claude Code，或重新加载 skill 列表。之后直接描述你的育儿问题即可，skill 会根据描述自动触发；也可以显式说“用 adler-parenting 帮我分析”。

### Claude.ai

把 `adler-parenting` 文件夹压缩为 zip，确保 `SKILL.md` 位于压缩包根目录（压缩文件夹内部内容，而不是把文件夹本身再套一层）。如果你的环境支持 `.skill` 文件上传，可以直接上传这个 zip。

### 其他环境

`SKILL.md` 是标准的 Markdown + YAML frontmatter，`references/` 是普通 Markdown。任何支持“按需读取参考文件”的 agent 环境都可以使用；不依赖 Obsidian、数据库或外部 API。

## 使用示例

```text
我家孩子8岁，每天晚上刷牙洗脸都要催很多遍，最后我吼他他才去。今晚我又气得想打他，怎么办？
```

```text
我希望我的孩子独立、自律。孩子8岁，现在每天作业都要我催，书包也我收。作为家长我该怎么做？
```

```text
4岁孩子在超市要玩具，不给买就躺地上哭，我每次都妥协。今天又来了，我该怎么办？
```

```text
4岁孩子发脾气，能不能让他去房间冷静？积极暂停到底怎么用？
```

```text
孩子不写作业，我没收他最喜欢的玩具，可以吗？
```

## 证据与边界

- 《孩子：挑战》出版于 1964 年，是临床经验总结，不是现代对照研究。
- 《正面管教》是阿德勒、德雷克斯思想的系统化实践版本；实践性强，但不能宣称“已被随机对照试验证明”。
- 四种行为目的有启发性，但缺乏直接实证验证，且容易被误判；主要适用于约 10 岁以下儿童；11–12 岁只能参考，13 岁以上不适用。
- 自然后果和逻辑后果在“与行为直接相关、不剥夺基本需要、不带惩罚心态”时才有条件成立；否则容易变成变相惩罚。优先关注解决问题。
- 积极暂停如果被用作隔离、惩罚、锁门，会偏离本意；3 岁以下不用。
- 阿德勒取向家长课程（如 STEP）的元分析显示中等效果，主要体现在家长态度和感知上，效果会随时间衰减；STEP 不等同于正面管教。
- 书中部分内容已过时：1960 年代性别角色、核心家庭假设、电视章节、部分案例语气，以及个别体罚情节。
- 详细说明和来源见 `references/evidence.md`。
