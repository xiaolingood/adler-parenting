# 方法与话术

正面管教的工具定义、年龄矩阵和常见误用以 `positive-discipline.md` 为准；本文件不重复步骤，只放场景话术和本文件独有的内容（后果安全清单、修复性道歉、情绪共调、作业支持、屏幕规则、兄弟姐妹冲突）。

一次只选一个主要工具。不要在同一段建议里同时让家长改五件事。

## 鼓励而不是空泛表扬

**什么时候用**：孩子努力了、尝试了、贡献了，或者遇到挫折时。

**怎么做**：

- 描述你看到的具体行为：“我看到你自己把书包放好了。”
- 感谢贡献：“你帮我把碗端过来，我省了一趟。”
- 关注过程：“这道题你试了三种方法。”
- 表达信任：“你觉得下一步可以怎么做？需要我时我在。”
- 失败时：“这次没成，你想再看看哪里卡住了吗？”

**不要做**：用“你真聪明/真棒”评价人格；只在成功时出现；把鼓励变成交换条件。

**为什么有效**：把注意力放在可控的努力和贡献上，支持能力感和自主感，而不是依赖外部评价。

## 有限选择

**什么时候用**：孩子需要配合，但你想减少权力争夺。

**怎么做**：

- 只给两个你都能接受的选择：“你现在去刷牙，还是听完这首歌去？”
- 选择要具体、可执行、与当下有关。
- 孩子选了就执行；不选就由你按事先约定行动。
- 涉及安全、健康的事不做选择：“过马路必须牵手，这个不能选。”

**不要做**：给假选择（“你想现在去还是马上就去”）；选项里有一个你其实不接受；孩子选了又反悔。

**为什么有效**：既保留边界，又给孩子自主感，降低“被控制”的对抗。

## 自然后果与逻辑后果

**先记住顺序**：先看安全 → 先连接 → 先关注解决问题 → 最后才考虑后果。后果不是首选，也不是“不吼叫的惩罚”。

**什么时候用**：孩子有能力承担、后果安全、与行为直接相关；而且已经尝试过一起解决问题。

**安全清单**（任何一项不满足就不要用）：

- 不涉及人身伤害、走失、交通、溺水、烫伤、冻伤、误食、被侵害。
- 不剥夺食物、水、睡眠、医疗、安全感。
- 不羞辱、不公开处刑、不威胁抛弃。
- 孩子年龄和能力足以理解并承受。
- 后果与行为直接相关，不是家长临时加的惩罚。
- 家长能稳定执行，不带报复心。

**自然后果**：让事情自然发生。例如不穿外套会冷（在安全范围内）、不吃饭会饿到下一餐（健康孩子、医生没有特殊要求）。

**逻辑后果**：由家长安排一个与行为直接相关的结果。例如：

- 玩水把地板弄湿 → 一起擦干。
- 到点不收玩具 → 玩具暂时收起来，明天再玩。
- 出门磨蹭 → 按约定时间出发，孩子承担迟到的自然后果（提前和学校/老师沟通，避免羞辱）。
- 屏幕时间到点不关 → 第二天减少相应时间，事先约定。

**话术**：

- “水洒了，我们把它擦干。”
- “玩具到点要回家。你可以现在收，或者我帮你收起来，明天再拿。”
- “我们约好八点出门。八点我会出发。”

**不要做**：说“我早就告诉过你”“这就是教训”；临时加码；因为生气而执行；把后果变成长时间冷战。

**现代校验**：逻辑后果只有在“与问题直接相关、不剥夺基本需要、不带惩罚心态”时才不同于惩罚。否则就是变相惩罚。证据仍在积累，别把它当成万能工具。

**替代首选**：先问“这个问题怎么解决？”用头脑风暴和 3R1H（相关、尊重、合理、有帮助）找方案。只有在需要体验结果时，才用后果。

## 建立常规 / 日常惯例表

**什么时候用**：反复发生的时间点冲突（早晨、作业、睡前、出门）。

**怎么做**：

- 和孩子一起列出流程，不超过 4–6 步。
- 用图片、清单或计时器做视觉提示。
- 提前预告转换：“五分钟后关电视。”
- 固定顺序，减少每天重新谈判。
- 每周回看一次，调整不合理的部分。

**话术**：

- “我们的早晨流程是：穿衣、刷牙、吃饭、穿鞋。你想先做哪一步？”
- “计时器响了就关屏幕，这是我们一起定的。”

**不要做**：把常规变成军事化管理；孩子慢了就代劳；每天临时改流程。

## 花时间训练

**什么时候用**：孩子还不会做，或做得慢、做得乱。

**怎么做**：

- 选一个不赶时间的时刻。
- 分解步骤，一次教一小步。
- 示范一遍，让孩子做一遍，再一起做一遍。
- 允许犯错，不追求完美。
- 练几次后再要求独立完成。

**话术**：

- “今天不赶时间，我们一起练一次怎么收书包。”
- “这一步你做，我在旁边看着。”

**不要做**：在迟到前五分钟才开始教；孩子做不好就抢过来；把训练变成考试。

## 退出冲突

**什么时候用**：双方情绪升级、开始重复旧台词、你感觉自己要爆发。

**怎么做**：

- 用一句话说明你要暂停：“我现在很生气，需要冷静一下，十分钟后再谈。”
- 离开现场，做深呼吸、喝水、走动。
- 不摔门、不讽刺、不消失一整天。
- 平静后回来，简短处理问题，不翻旧账。

**不要做**：把离开当惩罚；走了就不回来；在孩子害怕时突然消失。

**为什么有效**：切断升级循环，给双方情绪降温。孩子也会看到一种处理冲突的方式。

## 邀请合作（日常四步）

**什么时候用**：需要孩子配合做家务、出门、收拾、改变流程。

**四步**：

1. **描述问题**，不指责：“地上有很多积木，走路会踩到。”
2. **表达需要**：“我需要一条能走的路。”
3. **邀请参与**：“你愿意收积木，还是收书？”
4. **感谢贡献**：“谢谢你，现在好走多了。”

**注意**：

- 在气氛好时谈，不在冲突高峰谈。
- 让孩子参与制定规则，而不是被动接受。
- 说了就执行，不反复讨价还价。
- 这不是《正面管教》的“赢得合作四步”；后者用于冲突修复，见下一节。

## 赢得合作四步（冲突修复）

**什么时候用**：双方已经对立，孩子不愿听，先修复关系再谈规则。

四步的顺序和要点见 `positive-discipline.md`。可直接用的话：

- “我知道你不想停。换我我也不想。但我现在很担心迟到。我们一起想个办法，好吗？”

不要把“理解”当同意，也不要表面邀请、最后强制。

## 积极暂停

**什么时候用**：双方情绪高涨，继续谈只会升级；家长自己快失控。

工具定义、年龄边界和禁忌见 `positive-discipline.md`。可直接用的话：

- “你需要去冷静角待一会儿吗？还是想让我陪你坐一会儿？”
- “我现在需要暂停五分钟。五分钟后我们再谈。”

不要把暂停当惩罚：不锁门、不关小黑屋、不在冲突高潮说“你给我去暂停”。

## 家庭会议

**什么时候用**：需要全家一起定规则、解决反复出现的问题、分配家务。

议程、角色、年龄适配和常见误用见 `positive-discipline.md`。可直接用的话：

- “我们先从感谢开始。这周谁做了一件让你觉得舒服的事？”
- “这个问题先不急着怪谁，我们想想有哪些办法。”
- “这个方案先试一周，下周看看有没有用。”

## 关注解决问题

**什么时候用**：冲突过后、需要定规则、反复出现的问题。

3R1H 标准和完整步骤见 `positive-discipline.md`。可直接用的话：

- “这个问题，你觉得可以怎么解决？”
- “我们先想五个办法，先不评价。”
- “这个办法符合相关、尊重、合理、有帮助吗？”

不要把“解决问题”变成“换个方式让孩子认错”。

## 特殊时光

**什么时候用**：日常预防；孩子经常用问题行为争取注意；关系变紧张。

频率、年龄建议和禁忌见 `positive-discipline.md`。可直接用的话：

- “今晚八点到八点十分，是我们的特殊时光。你想做什么？”
- “这段时间我只陪你，不谈作业。”

## 启发式提问

**什么时候用**：孩子有情绪、犯错、冲突后，想让他自己思考。

完整示例和年龄提示见 `positive-discipline.md`。常用问题：

- “发生了什么？”
- “你觉得可以怎么解决？”
- “下次你想试试什么？”

避免“你为什么又这样”和一连串封闭审问。

## 错误是学习的机会

**什么时候用**：孩子犯错、家长自己犯错、冲突修复。

步骤和年龄提示见 `positive-discipline.md`。可直接用的话：

- “犯错没关系。我们看看能怎么修。”
- “你从这件事里学到了什么？”
- “我刚才做错了，对不起。我会改。”

## 倾听与对话

**什么时候用**：孩子有情绪、有抱怨、有冲突想讲。

**怎么做**：

- 停下手里的事，看着孩子。
- 复述你听到的：“你觉得很不公平，因为弟弟先拿了你的玩具。”
- 先不急着解决，问：“你想让我听，还是一起想办法？”
- 等孩子说完，再表达你的看法。

**话术**：

- “我在听，你慢慢说。”
- “这件事让你很生气，是吗？”
- “你觉得可以怎么办？需要我做什么？”

**不要做**：打断、立刻讲道理、比较、否定感受（“这有什么好哭的”）。

## 修复性道歉

**什么时候用**：家长吼了、讽刺了、动手了，或说了伤人的话。

**怎么做**：

- 先确保安全，不在情绪高峰道歉。
- 具体承认：“我刚才吼你了，是我不对。”
- 不找借口：“因为你太气人”不是道歉。
- 说明下次怎么做：“我下次会先离开五分钟。”
- 如果涉及体罚，明确承诺不再动手，并寻求支持。

**话术**：

- “我刚才说话很难听，伤到你了，对不起。我会改。”
- “你可以生气，但我那样说不合适。”

**为什么有效**：修复关系，示范承担责任，而不是要求孩子先原谅。

## 情绪共调（现代补充）

**什么时候用**：孩子大哭、暴怒、崩溃，讲道理无效时。

**怎么做**：

- 先降低刺激：关小声音、离开人群、蹲下来。
- 用简短的话命名情绪：“你很失望，因为不能买。”
- 提供身体支持（如果孩子接受）：靠近、递水、轻拍。
- 等情绪下降，再谈规则或解决办法。
- 家长自己先稳住；孩子会借你的状态来调节。

**不要做**：在孩子崩溃时长篇说教；用“再哭就不要你了”威胁；强迫孩子立刻停止。

**为什么有效**：情绪调节能力是逐步发展出来的，孩子需要成人先帮他稳住，再学会自己稳住。

## 作业支持（现代补充）

**什么时候用**：作业拖延、启动困难、注意力分散、亲子作业冲突。

**怎么做**：

- 固定时间、固定位置、减少干扰。
- 开始前一起列清单，先做最容易启动的一项。
- 用短时段 + 休息（例如 15 分钟 + 5 分钟）。
- 家长提供环境和支持，不替孩子写，也不全程盯着。
- 作业是孩子的事；完成后让他自己收书包。
- 如果长期困难，排查阅读、书写、注意力、睡眠、情绪等因素。

**话术**：

- “你打算先做哪一科？需要我帮你计时吗？”
- “卡住了可以问我，但我不会替你做。”
- “九点收作业，剩下的明天和老师说明。”

**不要做**：坐在旁边逐题纠正；用奖励交换作业；因为作业打骂；把家长的焦虑变成孩子的任务。

## 屏幕规则（现代补充）

**什么时候用**：屏幕时间冲突、到点不关、偷偷玩、影响睡眠或学习。

**怎么做**：

- 和孩子一起定规则：时长、时段、内容、结束方式。
- 规则要具体：“晚上八点半关屏幕，设备放在客厅充电。”
- 提前预告结束：“还有十分钟。”
- 家长一致执行，不用屏幕当奖惩。
- 提供替代活动，不只说“不许玩”。
- 家长自己也要示范。

**话术**：

- “我们约好八点半关。你想自己关，还是我提醒你一次？”
- “时间到了，设备留在客厅。明天还可以玩。”

**不要做**：临时加码；情绪化没收；用屏幕换成绩；规则只对孩子不对大人。

## 兄弟姐妹冲突（现代补充）

**什么时候用**：争抢、告状、比较、打闹升级。

**怎么做**：

- 先确保安全，制止伤害。
- 不急着当裁判，不预设“大的让小的”。
- 分别听，再一起谈：“你们都觉得委屈，我们怎么解决？”
- 把问题交还给双方，让他们提出方案。
- 避免比较和贴标签（“你看哥哥多懂事”）。
- 公平不等于相同；按年龄和需要调整。

**话术**：

- “我看到你们都很生气。先分开冷静一下，等会儿我们一起想办法。”
- “这个玩具谁先拿到的？你们能商量一个轮流的方法吗？”

**不要做**：不问缘由各打五十大板；强迫分享；让一个孩子长期承担照顾另一个的责任。
