# 术语表

对家长输出时，用这里的说法，保持一致。不同书、不同译者可能用不同译名；不要在同一次回答里混用。

| 术语 | 含义 | 备注 |
|---|---|---|
| 和善而坚定 | 既尊重孩子，也尊重自己和情境；不是和善与坚定二选一 | 《正面管教》的核心态度 |
| 坚定而非专制 | 边界稳定、执行平静，不靠吼叫、威胁、体罚 | 《孩子：挑战》的说法，可与“和善而坚定”并用 |
| 积极暂停 | 情绪高涨时，到一个让自己感觉好起来的地方/做法 | 不是惩罚性隔离；3 岁以下不用 |
| 惩罚性暂停 | 把孩子赶走、隔离、关房间，作为惩罚 | 不推荐 |
| 日常惯例表 | 把每天重复的流程做成可视化顺序，孩子参与制作 | 也叫“常规表”“流程表” |
| 家庭会议 | 全家定期开会：感谢、议程、头脑风暴、决定、跟进 | 不是批斗会；4 岁以上可参加简化版 |
| 班会 | 班级里的定期会议，结构类似家庭会议 | 教师场景，家长不必自己开 |
| 关注解决问题 | 把注意力从“谁错了/怎么罚”转到“怎么解决” | 优先于后果 |
| 3R1H | 相关、尊重、合理、有帮助 | 判断解决方案的标准 |
| 自然后果 | 行为自然带来的结果，没有家长人为安排 | 必须安全、孩子能承受 |
| 逻辑后果 | 家长安排的、与行为直接相关的结果 | 容易变成变相惩罚；不是首选 |
| 鼓励 | 关注努力、过程、贡献、感受 | 不是空泛表扬 |
| 表扬 | 评价式肯定，如“你真棒/真聪明” | 容易造成外部评价依赖 |
| 特殊时光 | 不受打扰的一对一时间，孩子选活动 | 预防性，不是奖励 |
| 错误目的 | 孩子用不当行为追求归属感/价值感的四种可能目的 | 假设，不是诊断 |
| 四种行为目的 | 寻求过度关注、寻求权力、寻求报复、自暴自弃 | 主要适用于约 10 岁以下 |
| 连接先于纠正 | 先共情、倾听、建立关系，再设边界、解决问题 | 连接不等于让步 |
| 有限选择 | 给两个（偶尔三个）家长能接受的选择 | 不是假选择 |
| 启发式提问 | 用开放问题让孩子自己思考 | 少问“为什么”，多问“发生了什么/怎么办” |
| 有效管教的四个标准 | 和善而坚定、归属感/价值感、长期有效、教技能 | 判断方法是否靠谱 |
| 七项感知力和技能 | 能力感、价值感、影响力、内省、沟通、整体把握、判断 | 长期目标 |
| 错误是学习的机会 | 把错误当成修复和学习的入口，不是羞辱的理由 | 家长先示范 |
| 赢得合作四步 | 理解、共鸣、表达感受、邀请解决 | 与“邀请合作”的日常四步不同 |
| 邀请合作 | 描述问题、表达需要、邀请帮忙、感谢贡献 | 日常协作，不是冲突修复 |

## 输出规则

- 用名称，不用编号；不要写“原则 12”“第 24 条”。
- 同一次回答只选一个主要工具，其他放到“如果继续”或“长期”。
- 提到年龄边界时，直接说“3 岁以下不用积极暂停”“家庭会议 4 岁以上简化版”。
- 不确定时，用“可能”“更像是”“确定性中等”，不要装成诊断。
